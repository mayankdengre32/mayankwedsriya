# 💍 Mayank Weds Riya — Luxury Digital Wedding Invitation (Vite Project)

A mobile-first, continuous-scroll digital wedding invitation crafted with a royal deep velvet burgundy and gold aesthetic.

---

## ⚡ Development & Commands

This project is powered by **Vite** for rapid hot-reloading development and optimized production bundling.

### 1. Start Development Server
```bash
npm run dev
```
Starts the Vite local server at `http://localhost:5173/` with Instant HMR.

### 2. Build for Production
```bash
npm run build
```
Creates an optimized, minified bundle in the `dist/` directory ready to be hosted anywhere.

### 3. Preview Production Build
```bash
npm run preview
```
Runs a local web server to test the generated `dist/` production build.

## 🚀 Easy Deployment (Netlify / Vercel / GitHub Pages)

- **Netlify**:
  - Connect your repository or drag-and-drop the `dist/` folder onto [app.netlify.com/drop](https://app.netlify.com/drop).
  - Build command: `npm run build`
  - Publish directory: `dist`
- **Vercel**:
  - Preset: `Vite`
  - Output directory: `dist`
